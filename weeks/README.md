# Week 02 — SCHEDULER.py · Полный scheduling cycle

Основной материал находится в [`docs/week_02_report.md`](docs/week_02_report.md).

**Задача недели:** проследить по коду полный scheduling cycle — данные UE → выбор → распределение ресурсов → изменение буферов и статистики, и подготовить схему вызовов для одного небольшого сценария с указанием входов, выходов и побочных изменений состояния.
